Calculation inputs

When your AI client invokes JIN, the server receives the tool arguments selected by the client. These may include chemical formulas, mixture ratios, mass, area, thickness, density, concentration, energy, and requested atomic edges or lines. JIN processes these inputs to calculate or retrieve results and returns the results to the client.

The inspected server implementation has no function for retrieving complete conversation transcripts and does not actively save calculation requests or results to an application database or file. Information entered into a conversation may nevertheless be included in tool arguments by the AI client.

Hosting and technical logs

JIN is hosted on DigitalOcean App Platform. Technical runtime logs are generated, including request timing, connection addresses, request paths, response status codes, MCP request types and diagnostic messages. Errors may contain input values such as an invalid chemical formula. The absence of application-level storage does not mean that no input can appear in an error log.

No log-forwarding destination is currently configured in DigitalOcean App Platform. Only Yuwei Liu has access to the application's DigitalOcean management account. Hosting-provider processing is separate from this account-access statement.

Runtime-log retention is governed by the hosting platform and its configuration; a fixed retention period has not been verified. This notice does not promise immediate deletion or zero retention of platform logs.

Support correspondence

If you contact support, your email address and message contents are used to reply and investigate the issue. The publisher retains support correspondence for one year after the inquiry is resolved, then deletes it.

AI platform and this website

The AI platform handles conversations and tool exchanges according to its own policies. This static website is prepared for hosting on GitHub Pages. These pages contain no publisher-added analytics scripts, tracking cookies, or contact forms. Hosting providers may process technical connection data independently of the page code.

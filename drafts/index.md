# BL14B2 Assistance + JIN

Publication copy — draft for publisher review.

BL14B2 Assistance + JIN helps SPring-8 BL14B2 users consult beamline reference materials and prepare XAFS measurements. It combines bundled Introduction and SOP documents with JIN calculation tools.

## Features
- Reference-grounded explanations of documented beamline capabilities and procedures.
- XAFS absorption calculations for solid and solution samples.
- Tabulated absorption-edge and fluorescence-line energies using xraylib.

Calculations depend on the supplied inputs and model assumptions. The plugin does not operate beamline hardware or grant experimental approval. Confirm operational decisions with beamline staff.
